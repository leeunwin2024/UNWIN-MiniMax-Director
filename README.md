# UNWIN MiniMax Director

A local ComfyUI MiniMax H3 video director project.

## Current release

The current working package is **v1.4.2**, with H3 Standard / Turbo / Fast presets, automatic diffusion/text/VAE selection, and 720p / 1080p / 2K delivery profiles.

**Source upload pending:** This repository has been initialized, but the full v1.4.2 source archive has not yet been committed. Do not install from this repository until the source files are published.

## Notes

Native H3 generation and 1080p/2K delivery are distinct; higher delivery resolutions require upscaling. GPU rendering and model compatibility still require testing.

# Changelog

This changelog summarises packaged development milestones. Feature availability depends on the version of the source files installed.

## v1.4.5 — Master & Scene Prompts
- Master Director Prompt shared across scenes.
- Editable scene-specific sub-prompts.
- Combined render prompt preview.
- Continuity guidance integrated into scene render prompts.

## v1.4.4 — Continuous Audio
- Project-level soundtrack on final stitched output.
- Music-only and music-plus-scene-audio mix modes.
- Music volume control and optional looping.

## v1.4.3 — Security Hardening
- Defensive timeline/cast JSON parsing.
- Resolved asset paths and boundary validation.
- Safer shell-free helper invocation.
- Graceful optional import handling.

## v1.4.2 — 2K Delivery
- Delivery/export presets including 2560×1440.
- Model profiles for H3 Fast, Standard and Turbo.
- 2K is an upscaled delivery format, not native H3 generation.
